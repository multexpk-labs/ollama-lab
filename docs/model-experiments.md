# Model Experiments

Model experiments should be reproducible.

## Record

```text
Date:
Ollama version:
Model:
Tag:
Quantization:
CPU:
RAM:
GPU:
VRAM:
Context:
Prompt type:

```

## Compare Carefully
Keep hardware, runtime version, prompt, context, generation settings, concurrency, and measurement method controlled where practical.

Performance and output quality are separate dimensions.
